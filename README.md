# Recipe Saver – Flutter GitHub Project

A ready-to-upload Flutter front-end implementation for the supplied Recipe Saver Figma concept.

## Figma source
https://www.figma.com/design/LRTUkzewgM5ZqfnGrXLshv/Recepie-saver?node-id=0-1&t=N1jRzwvfSR4687pm-1

## Included functionality
- Recipe home dashboard
- Recipe search
- Recipe categories
- Recipe detail screen
- Save/bookmark recipes
- Saved recipes screen
- Responsive Material 3 navigation

## Run locally
1. Install Flutter SDK.
2. Extract this project.
3. Run `flutter pub get`.
4. Run `flutter run`.

## GitHub upload
The extracted folder can be uploaded directly to a new GitHub repository. For a command-line upload:

```bash
git init
git add .
git commit -m "Initial Recipe Saver Flutter app"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Scope note
The supplied Figma URL could not be directly inspected by the generation environment. Therefore, this package implements the Recipe Saver concept and common recipe-saving interactions rather than claiming pixel-perfect conversion of every Figma frame. Exported Figma screenshots or assets can be used for exact visual matching.
